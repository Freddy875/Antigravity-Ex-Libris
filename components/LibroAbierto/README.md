El libro abierto: dos hojas de papel entre las tapas del color del lomo, con la portada que gira sobre el lomo al aparecer.

**Qué das:** `titulo`, `autor`, `color` (el mismo del lomo), `categoria` (texto pequeño sobre el título: «Libro · Hábitos»), `resumen` para la hoja izquierda, `encabezado` para la hoja derecha (por defecto «Notas») y `children` con el contenido de la hoja derecha. `animar={false}` lo muestra ya abierto.

**Contenido:** una cadena de texto se divide en párrafos por líneas en blanco; una lista de cadenas se convierte en viñetas; cualquier otro elemento se muestra tal cual.

**Cuándo usarlo:** para leer un tomo. Normalmente lo abre `Biblioteca` dentro de su velo; úsalo solo si construyes tu propia sala.

**Hazlo:**
- Usa el mismo `color` que el lomo, para que se sienta el mismo libro.
- Escribe la categoría también con palabras, aunque el color ya la sugiera.

**No lo hagas:**
- No cambies su tamaño por libro: el contenido largo se desplaza dentro de cada hoja.
- No pongas botones de cierre dentro de las hojas; el botón «Devolver al estante» va debajo del libro.
